# 对接结果状态码 v1.0 (Docking Result Status Codes)

**用途**：用于分级标记分子对接结果状态，将技术表现、结构特征以及生物学合理性统一编码，便于后续筛选、统计与分析。

## 🟢 R100s：优良对接，置信度高

| 编号 | 含义 | 情况描述 |
| :--- | :--- | :--- |
| **R100** | 口袋内稳定结合，多位姿一致 | 基准对接，所有配体均落在口袋内同一区域，位姿重复性好 |
| **R101** | 口袋内结合，但取向略有偏差 | 配体在口袋内，但朝向或构象与预期有轻微偏差，不影响整体判断 |
| **R102** | 口袋内结合，少数配体位姿偏离 | 多个配体中，少数出现口袋外位点，但大部分仍在口袋内 |
| **R103** | 口袋内结合，但偏于口袋一侧 | 配体富集于口袋内一角，可能反映亚位点偏好 |
| **R104** | 口袋内结合，但含一个稳定水桥 | 配体通过水分子与受体发生介导相互作用 |
| **R105** | 口袋内结合，配体构象与文献一致 | 位姿与已发表结构或实验数据高度吻合 |
| **R106** | 口袋内结合，存在两个相似亚位点 | 配体在两个相邻位点间交替 |
| **R107** | 口袋内结合，结合能偏弱 | 结合能较其他配体明显偏低，但仍满足阈值 |
| **R108** | 口袋内结合，需排除非特异性疏水作用 | 可能主要由疏水作用驱动 |
| **R109** | 口袋内结合，但锌指附近有额外接触 | 与锌指结构或附近残基发生额外相互作用 |
| **R110** | 口袋内结合，但口袋入口处有额外堆积 | 入口处存在分子堆积，可能反映别构调节信号 |

## 🟡 R200s：参考对接，待验证

| 编号 | 含义 | 情况描述 |
| :--- | :--- | :--- |
| **R200** | 口袋外紧贴表面富集 | 可能与疏水斑块或膜结合区域有关 |
| **R201** | 口袋外特定点位少量聚集 | 提示可能存在别构位点 |
| **R202** | 口袋内与口袋外双重富集（约5:5） | 可能是真实热点竞争或坐标偏差 |
| **R203** | 结合位点偏向口袋边缘 | 尚未进入深部口袋 |
| **R204** | 口袋外表面结合，但多个配体一致 | 提示区域可能具有功能性 |
| **R205** | 分子在多个不同结构区域富集 | 可能反映多个结合界面 |
| **R206** | 配体构象高度可变 | 提示口袋空间较大或未完全闭合 |
| **R207** | 结合能接近阈值 | 需进一步验证 |
| **R208** | 口袋内结合但位姿不稳定 | 可能因口袋柔性或坐标偏差 |
| **R209** | 配体与受体表面形成氢键网络 | 可能代表可逆弱相互作用 |
| **R210** | 口袋外富集但口袋内也有信号 | 优先考察表面结合意义 |

## 🔴 R300s：低置信度对接，需优化

| 编号 | 含义 | 情况描述 |
| :--- | :--- | :--- |
| **R300** | 完全无结合迹象 | 无明显结合信号 |
| **R301** | 配体与受体表面仅极少量接触 | 无富集区域 |
| **R302** | 位姿与实际口袋方向严重不符 | 结合模式完全相反 |
| **R303** | 口袋内结合但配体过大或过小 | 大小与口袋不匹配 |
| **R304** | 能量贡献主要来自于范德华力 | 缺乏氢键或静电作用 |
| **R305** | 口袋残基构成不合理 | 缺乏合理极性 or 芳香作用 |
| **R306** | 构象异常 | 存在物理不合理现象 |
| **R307** | 坐标与口袋偏差过大（>5Å） | 盒子中心偏离 |
| **R308** | 对接盒尺寸不足 | 无法覆盖口袋 |
| **R309** | 受体结构缺陷 | 关键残基缺失 |
| **R310** | 未预期计算错误 | 核心程序报错 |

---

## 🧬 R400s：生物学层面异常

| 编号 | 含义 | 典型情况 |
| :--- | :--- | :--- |
| **R400** | 配体在生物学上不适用于该受体 | 无已知活性记录 |
| **R401** | 配体与受体在进化上不匹配 | 结合信号弱或无 |
| **R402** | 已知拮抗剂/反向激动剂 | 占据口袋但无信号输出 |
| **R403** | 前体/代谢物形式 | 需代谢修饰 |
| **R404** | 受体在该组织/细胞中不表达 | 结合无生理意义 |
| **R405** | 需协同其他蛋白 | 单独对接无法体现活性 |
| **R406** | 多靶点分子 | 结合模式不唯一 |
| **R407** | 结合口袋涉及膜脂环境 | 需考虑脂质置换 |
| **R408** | 感知依赖特定构象状态 | 当前结构未反映 |
| **R409** | 天然底物范围宽泛，亲合力低 | 弱激动剂 |
